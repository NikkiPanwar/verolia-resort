# Veloria Resort 🌊✨

> **Veloria Resort** is an ultra-luxury 5-star hotel & wellness sanctuary web application crafted with React 19 and Vite. It offers an end-to-end guest experience with interactive suite reservations, 3-star Michelin dining bookings, Swiss thermal wellness treatments, in-room dining room service, chauffeur transfers, and an interactive 24/7 AI concierge.

---

## 🌟 Key Features

- **Suite & Villa Booking**: Interactive room selection with amenity breakdowns, 360° virtual tour previews, transparent pricing, and customizable VIP add-ons.
- **Quick Availability Search**: Real-time stay date, guest count, and suite availability filter widget.
- **Michelin-Starred Dining**: Table reservations for 4 signature restaurants with dietary preference options.
- **Swiss Thermal Spa & Wellness**: Treatment bookings for hydrotherapy, Ayurvedic massages, and sauna rituals.
- **In-Room Culinary Ordering**: Room service menu with shopping bag checkout and special culinary requests.
- **Luxury Transportation**: Private airport and yacht chauffeur booking with live rate calculators.
- **Events & Galas**: Private event inquiry system for destination weddings, summits, and anniversaries.
- **24/7 AI Concierge**: Interactive floating concierge chat providing automated, context-aware assistance.
- **Dynamic Theming**: Seamless luxury light & dark mode toggle with gold-tailored accents.

---

## 🚀 Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Typography**: Cinzel, Cormorant Garamond, Plus Jakarta Sans
- **Styling**: Vanilla CSS Design System with CSS Variables and Glassmorphism

## 💻 Getting Started

### Prerequisites
- Node.js (v18 or newer recommended)
- npm or yarn

### Installation

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open your browser at `http://localhost:5173` to explore Veloria Resort.

---

## 🛠️ Build & Lint

```bash
npm run build    # Build for production in /dist
npm run lint     # Lint codebase with oxlint
npm run preview  # Preview production build locally
```
